# LilyLake implementation plan

Execute inline under the user's explicit authorization; each milestone is committed and pushed.

1. Specification/research: environment inventory, primary sources, acceptance criteria; commit docs.
2. Music foundation: tests for valid notes, all 88 pitch names, tempo map inversion, quantization/voice overlaps, MIDI round-trip; implement schema, taxonomy, notation, MIDI and LilyPond modules. Compile multi-part adversarial scores and regression tests. Commit.
3. Renderer/data: tests for MIDI-to-audio alignment, deterministic generators and augmentation, split leakage; implement LilyPond compile, FluidSynth and procedural backends, exact compiled-MIDI labels, dataset manifests and coverage. Generate real paired examples. Commit.
4. Neural pipeline: tests for instrument/pitch tensor independence, mask and losses, gradients, repeat-note decoder, safe checkpoint save/resume; implement frontend, temporal network, targets, training, inference and metrics. Commit.
5. CLI/end-to-end: expose doctor, generate-data, train, evaluate, transcribe, render, validate, benchmark and regression-suite commands; config validation and diagnostics. Run complete CLI round-trip and tests. Commit.
6. Experiments: first fixed tiny-set sanity overfit, then unseen compositions, full-key and piano+violin suites, held-out engine tests. Profile CPU throughput; optimize measured bottleneck; retry after regression checks. Preserve checkpoints and honest reports.
7. Release documentation: installation, usage, schema, extension contracts, licensing, measured status and limitations. Run full tests, compileall and reproducibility/resume checks, push final verified changes and verify remote SHA.

## Verification commands
`python -m pytest`; `python -m lilylake doctor`; generated benchmark score compile; paired-data generation; training and resume; evaluate and transcribe unseen WAV; compile predicted score; render predicted score. Large training artifacts are excluded from Git; a small verified development checkpoint may be committed if reasonably sized and explicitly labeled non-production.
